## Como instalar

1. **Crie src/components/LogoLoop.tsx** Copie o conteúdo de `src/LogoLoop.tsx` e `src/LogoLoop.css` deste repositório. Esse efeito também tem LogoLoop.css: crie ao lado.
2. **Sem deps**
3. **Use na página**

   ```tsx
   <LogoLoop logos={[...]} speed={120} direction="left" fadeOut />
   ```
